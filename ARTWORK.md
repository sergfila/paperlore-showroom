# Иллюстрации шоурума

Восемь иллюстраций `assets/stages/` сгенерированы специально для публичной истории Paperlore встроенным ImageGen. Референс техники — карандашный эскиз из дневника 4iuaCraft Studios; сами сцены новые. Это концептуальная реконструкция процесса, не архивные фотографии рабочих досок и не макеты приложения.

Общая художественная постановка: горизонтальный редакционный рисунок 3:2 на тёплой бумаге, графит и умеренное количество цветных карандашей (шалфейный, охра, терракота), видимые штрихи, разные композиции, без текста и логотипов.

| Файл | Сюжетный запрос |
|---|---|
| `01-idea.webp` | Исследовательский лист с тремя вариантами мобильного UX, схемой пути пользователя и выбранным направлением. |
| `02-mechanics.webp` | Инженерная тетрадь: контуры деталей, направляющие, узел соединения, удачное и неудачное попадание. |
| `03-paper-world.webp` | Сравнение трёх способов изображения одного сюжета — плоского, избыточно текстурного и многослойного бумажного. |
| `04-playable-game.webp` | Проверка переноса детали из ленты на поле, сцепления, панорамирования и масштаба на мобильном экране. |
| `05-collection.webp` | Контактный лист проверки сюжетов: разные композиции, пометки о повторениях, масштабах и читаемости. |
| `06-progress.webp` | Схема альтернатив прогрессии категорий, порогов открытия, шкал и таблицы проверок. |
| `07-tutorial.webp` | Раскадровка жестов обучения: взять, перенести, соединить, сдвинуть поле двумя пальцами. |
| `08-release.webp` | Лист релизной проверки: устройство, чек-лист, график производительности, варианты управления масштабом и пакет публикации. |

Готовые WebP-файлы сжаты с качеством 82 для быстрой загрузки README. Типографику намеренно оставили за пределами изображения, чтобы подписи оставались доступными и редактируемыми.
